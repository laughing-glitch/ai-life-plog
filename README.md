# AI 生活 Plog

把主体已经拍清楚、背景和光线不理想的食物、饮品和日常用品照片，改造成真实、克制的 3:4 生活化 Plog。

适合手持咖啡、办公室零食、家中日常用品等生活随手拍。不适合需要精确保留人脸、文字、商标、证件、城市建筑或现场真实性的照片。

## 安装

仓库地址

`https://github.com/laughing-glitch/ai-life-plog`

### Codex

把仓库地址发给 Codex，并说

> 请安装这个仓库里的 ai-life-plog Skill。

安装后重新打开 Codex。

### WorkBuddy

在 WorkBuddy 的技能安装入口粘贴仓库地址，安装 `ai-life-plog`，然后重新打开 WorkBuddy。

## 使用

上传一张照片，然后说

> 用 AI 生活 Plog 把这张照片改得更适合发布。

也可以指定一个普通生活场景

> 保留手里拿咖啡的动作，把背景改成明亮、真实的写字楼通勤场景。

默认只生成一张 3:4 竖图。生成式改造可能重画包装文字、商标和局部纹理，发布时请标注 AI 辅助改造。
